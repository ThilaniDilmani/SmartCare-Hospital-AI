# Literature Review

This folder contains the literature review materials for the SmartCare Hospital AI project.

## Contents

- **references.bib** — BibTeX file containing citations for all papers reviewed and selected for this project. Add new entries here as papers are found and included.
- **AI research.xlsx** — Spreadsheet tracking papers under consideration, including title, authors, year, key findings, and relevance to the project.

## Workflow

1. Search for relevant papers on healthcare AI, clinical decision support, predictive modeling, etc.
2. Log candidate papers in `AI research.xlsx` with a brief summary and relevance rating.
3. For papers selected to cite in the final report/thesis, add a corresponding BibTeX entry to `references.bib`.
4. Keep entries consistent in formatting (author names, journal names, etc.) to avoid citation errors later.

## Notes

- Use consistent citation keys in `references.bib` (e.g. `authorYear`, like `smith2023`).
- Update this README if the review process or folder structure changes.
